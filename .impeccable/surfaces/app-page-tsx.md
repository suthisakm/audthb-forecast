# Surface: / (AUD/THB Forecast Dashboard, whole page)

Mode: Operate. Audience: the owner/developer (and anyone they share the read-only URL with), scanning multiple FX signals to decide whether money should move between AU and TH soon. Task: read the Core FX Score, its seven factors, and whether the underlying feeds are actually fresh, in one glance. Constraints: single currency pair, free-tier data only, never framed as financial advice, every accuracy claim grounded in the live Track Record.

## Direction contract

THESIS: The dashboard reads as a daily nautical almanac page -- a fixed table of precisely computed daily figures a navigator would trust their position to -- refusing both the SaaS card-grid default and the glowing instrument-panel/seven-segment register this project tried and the user rejected as hard to read.

OWN-WORLD: Cream/ivory page ground, near-black ink text, a single muted brass/ochre rule color for section dividers and running heads -- kept deliberately restrained per the user's explicit "minimal" steer: generous whitespace, thin hairline rules only, no ornamental borders, no vintage texture or gilt flourish. Every number sits in a plain formal serif (or clean tabular-figure) face, right-aligned in ruled columns, never a display gimmick. A stale or missing value prints as a lightly greyed numeral held in its ruled cell -- not blank, not an unlit segment (raised from the declined seven-segment challenger, translated into plain ink).

STORY: The visitor reads the page exactly like consulting today's almanac table before taking a sighting: one authoritative daily figure at the top, every supporting computation ruled out beneath it in strict rows, so the whole page reads as a single trusted, dated instrument -- calm and uncluttered, not a period pastiche.

FIRST VIEWPORT: Hero is the almanac's masthead: a slim date band, then the AUD/THB figure and Core FX Score as the two largest tabular entries side by side in plain serif numerals, ruled columns of supporting figures beneath. The theme toggle settles with a tactile snap rather than an instant flip (raised from the declined cassette-futurism challenger); the header band carries a subtle session-time tint -- Asian/London/NY -- instead of a static color (raised from the declined cyclorama challenger). Both raises stay quiet, not decorative, in keeping with the minimal steer.

FORM: The Nautical Almanac -- candidate 7 of 7 on the re-roll-1 resonance-ordered list (Academic Transcript, Bond Prospectus/Tombstone, Actuarial Rate Table, Regulatory Filing, Notarized Certificate, Nautical Chart, Nautical Almanac), dealt by re-roll 1, seed key c46f8631. User steer: "minimal" -- restraint governs every rendition choice below.
